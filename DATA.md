# Datasets

## Captioning

- maya-multimodal/pretrain (~550k RU) - translated LLaVA-Pretrain /
https://huggingface.co/datasets/maya-multimodal/pretrain

- piyushsinghpasi/mscoco-multilingual-30k (~30k RU) - translated English MSCOCO caption / https://huggingface.co/datasets/piyushsinghpasi/mscoco-multilingual-30k

- d0rj/ShareGPT4V-ru (~102k RU) - ShareGPT4V / https://huggingface.co/datasets/d0rj/ShareGPT4V-ru

## VQA / Reasoning

- deepvk/GQA-ru (~40k RU) - translated GQA / https://huggingface.co/datasets/deepvk/GQA-ru

- deepvk/LLaVA-Instruct-ru (~150k RU) - translated LLaVA-Instruct / https://huggingface.co/datasets/deepvk/LLaVA-Instruct-ru

- ByteDance/MTVQA (~2k RU) - native / https://huggingface.co/datasets/ByteDance/MTVQA

## OCR

- RusTitW (~20k RU + ~900k synth) - native / https://www.kaggle.com/datasets/hardtype/rustitw-russian-language-visual-text-recognition

- deepcopy/synthetic-handwritten-cyrillic-180k (~180k RU) - single word / https://huggingface.co/datasets/deepcopy/synthetic-handwritten-cyrillic-180k

- deepcopy/DonkeySmall-OCR-Cyrillic-Printed-8 (~1M RU) - single word / https://huggingface.co/datasets/deepcopy/DonkeySmall-OCR-Cyrillic-Printed-8
